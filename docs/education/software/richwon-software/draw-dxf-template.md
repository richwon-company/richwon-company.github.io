# 도안 그리기

---

## 📝 준비물
- Type3로 만든 도안

---

## 📋 작업 순서

### 1단계: 도안 준비하기
- Type3 프로그램으로 도안을 그립니다.

   ![01 도안 샘플](/img/도안작성/01%20도안%20샘플.png)

- 좌표를 0, 0으로 변환해야 합니다. 도안을 전체 선택 한 뒤 드래그 하는 상태에서 F2키를 누르면 **정밀한 위치점**창이 나타납니다.

   ![01-1 도안 좌표 이동](/img/도안작성/01-1%20도안%20좌표%20이동.png)

- 절대좌표 이동을 클릭하고 왼쪽 아래 좌표의 X, Y 좌표가 0, 0이 되도록 수정하면 됩니다.

   ![01-2 정밀한 위치점](/img/도안작성/01-2%20정밀한%20위치점.png)

- 좌표를 수정하고 나면 다시 도안을 전체 선택하고 내보내기를 합니다.

   ![02 파일 내보내기](/img/도안작성/02%20파일%20내보내기.png)

- 파일을 내보내고 저장한 위치를 기억합니다.

   ![02-1 파일 내보내기 창](/img/도안작성/02-1%20파일%20내보내기%20창.png)


### 2단계: 캐드에서 글자 입력하기

#### Type3에서 작성된 도안을 캐드로 가져와서 수정해야 합니다.

- Type3에서 작성된 도안을 DXF 파일로 내보내면 글자가 전부 선으로 변환되어 내보내기 됩니다. 그래서 다시 글자로 바꾸는 작업을 해야 합니다.
- 캐드에서 이전에 내보내기를 한 도안 파일을 열어줍니다.

   ![03 CAD에서 파일 열기](/img/도안작성/03%20CAD에서%20파일%20열기.png)

- 나중에 선으로 이루어진 글자들은 한번에 지울 예정입니다. 쉽게 하기 위해 그룹을 지정합니다.  
  홈 메뉴에 있는 그룹 버튼을 클릭하거나 `GROUP` 명령어를 사용합니다.

   ![03-1 지울 내용 그룹 지정](/img/도안작성/03-1%20지울%20내용%20그룹%20지정.png)

- 캐드에서 `주석 > 단일 행` 버튼을 클릭하거나 명령어 `TEXT`를 입력하여 문자 생성을 시작합니다.

  ![04 TEXT 객체 생성 시작](/img/도안작성/04%20TEXT%20객체%20생성%20시작.png)

- TEXT를 생성할 위치에 마우스로 클릭해줍니다. 나중에 X, Y 좌표를 직접 수정할 예정이니 아무 곳에 만들어도 상관없습니다.

  ![04-1 TEXT 객체 시작 위치](/img/도안작성/04-1%20TEXT%20객체%20시작%20위치.png)

- TEXT의 글자 크기를 지정합니다. 나중에 스타일로 글자 크기를 지정할 예정이니 현재는 눈에 보이도록 적당한 크기를 적어줍니다.

  ![04-2 TEXT 객체 높이 지정](/img/도안작성/04-2%20TEXT%20객체%20높이%20지정.png)

- TEXT의 글자 회전 각도를 지정합니다. 기울어진 경우가 아니라면 `0`을 입력합니다.

  ![04-3 TEXT 객체 회전 각도 지정](/img/도안작성/04-3%20TEXT%20객체%20회전%20각도%20지정.png)

- TEXT의 글자를 입력합니다. 입력을 완료하면 `ctrl + enter`를 입력하여 글자 입력을 종료합니다.

  ![04-4 TEXT 객체 글자 입력](/img/도안작성/04-4%20TEXT%20객체%20글자%20입력.png)

### 3단계: 글자 스타일 생성 및 적용

- 캐드에서 `주석 > 문자 탭 > 오른쪽 하단 작은 화살표` 버튼을 클릭하거나 명령어 `STYLE`를 입력하여 스타일 생성을 시작합니다.

  ![05 STYLE 생성 시작](/img/도안작성/05%20STYLE%20생성%20시작.png)

- 스타일 창이 열리면 **새로 만들기** 버튼을 클릭합니다.

  ![05-1 STYLE 창](/img/도안작성/05-1%20STYLE%20창.png)

- 스타일 이름은 아무거나 입력하셔도 됩니다.

  ![05-2 새 문자 스타일](/img/도안작성/05-2%20새%20문자%20스타일.png)

- 새 문자 스타일 내용을 입력해줍니다.

  :::info
  * 글꼴 이름: 글자의 글꼴을 지정합니다.
  * 높이: 글자 크기를 지정합니다.
  * 폭 비율: 글자 자폭을 결정합니다. (예시. 85% -> 0.85)
  :::

  ![05-3 문자 스타일 내용 작성](/img/도안작성/05-3%20문자%20스타일%20내용%20작성.png)

- 새롭게 만든 스타일을 현재 작성되어 있는 TEXT에 적용합니다.  
  왼쪽에 떠있는 특성 창(`특성 > 문자 > 스타일`)에 스타일을 새롭게 만든 스타일로 바꿔줍니다.

  ![05-4 문자 스타일 적용](/img/도안작성/05-4%20문자%20스타일%20적용.png)

- 왼쪽에 떠있는 특성 창(`특성 > 형상 > X 위치, Y 위치`)에서 자리맞추기(글자 정렬), 폭 비율, 글자의 x, y 좌표를 수정합니다.  
  적당한 위치가 되도록 직접 좌표를 수정합니다.

  ![05-5 문자 스타일 적용](/img/도안작성/05-5%20문자%20x%20y%20좌표%20조정.png)

- 모든 문자를 위의 내용과 동일하게 수정해 줍니다.

  ![06 문자 완료](/img/도안작성/06%20문자%20완료.png)

- 이제 선으로 된 문자는 제거해줍니다. 
  그룹으로 지정된 **폴리선**을 선택합니다.

  ![07 폴리선 선택](/img/도안작성/07%20폴리선%20선택.png)

- 선택된 폴리선을 제거합니다.

  ![07-1 폴리선 그룹 선택](/img/도안작성/07-1%20폴리선%20그룹%20선택.png)

- 도안 그리기가 완료되었습니다. 이제 **2004버전**으로 저장하면 끝이 납니다.

  ![08 DXF 저장](/img/도안작성/08%20DXF%20저장.png)
