# 2단계: 자동화 프로그램으로 명판 도안(DXF) 만들기

---

## 📝 준비물
- 1단계에서 만든 **XLSX 파일**
- **DXF 템플릿 파일** (회사에서 미리 준비한 파일)
- **명판 자동화 프로그램**

---

## 📋 작업 순서

### 1단계: 자동화 프로그램 실행
- 바탕화면 또는 시작 메뉴에서 **명판 자동화 프로그램**을 실행합니다.

   ![14 프로그램 시작](/img/자동화%20프로그램/14%20프로그램%20시작.png)


    :::warning
    - **Window의 PC 보호**로 **인식할 수 없는 앱**라고 뜰 수 있습니다. 
    - **추가 정보**를 누르고 **실행** 버튼을 누르면 됩니다.
    :::

   ![12 Window 보호](/img/자동화%20프로그램/12%20Window%20보호.png)

   ![13 알 수 없는 게시자](/img/자동화%20프로그램/13%20알%20수%20없는%20게시자.png)

### 2단계: 도안 등록하기

#### 작업하고자 하는 도안을 등록해야 합니다. 

- **도안 추가** 버튼을 클릭합니다.
- **추가할 캐드 파일 찾기**에 캐드파일을 드래그 앤 드롭으로 넣거나

  ![15-1 명판 도안 등록 시작](/img/자동화%20프로그램/15-1%20명판%20도안%20등록%20시작.png)

  클릭하여 직접 찾습니다.

  ![15 명판 템플릿 불러오기](/img/자동화%20프로그램/15%20명판%20템플릿%20불러오기.png)

  불러온 파일이 맞는지 확인합니다.
  그리고 정보란(기본 정보, 텍스트 정보, 홀 정보)를 작성합니다.

  :::info
  아래의 항목은 자동으로 인식합니다. **제대로 가져오지 못했다면 정상동작 하지 않으니** 도안을 다시 그려주세요.
  * 가로, 세로 길이
  * 텍스트 정보
  :::

  ![15-2 명판 도안 정보 입력](/img/자동화%20프로그램/15-2%20명판%20도안%20정보%20입력.png)

### 3단계: 도안 대량 생성 시작

#### 등록된 도안으로 대량 생성하는 방법입니다.

  - **도안 목록** 메뉴로 가서 원하는 도안을 찾아주세요.

  ![16 명판 템플릿 불러옴](/img/자동화%20프로그램/16%20명판%20템플릿%20불러옴.png)

  - **도안 생성 시작** 버튼을 클릭해주세요.

  ![16-1 도안 생성 시작](/img/자동화%20프로그램/16-1%20도안%20생성%20시작.png)

  - 작업하고자 하는 엑셀 파일을 가져옵니다.

  ![16-2 엑셀 파일 선택](/img/자동화%20프로그램/16-2%20엑셀%20파일%20선택.png)

  ![17 엑셀 파일 불러오기](/img/자동화%20프로그램/17%20엑셀%20파일%20불러오기.png)

  오른쪽 위에 엑셀 파일명이 뜹니다. 불러온 파일이 맞는지 확인합니다.

  ![18 엑셀 파일 불러옴](/img/자동화%20프로그램/18%20엑셀%20파일%20불러옴.png)
   
  원하는 텍스트 열을 선택합니다.

  ![19 엑셀 파일에서 사용할 열 정하기](/img/자동화%20프로그램/19%20엑셀%20파일에서%20사용할%20열%20정하기.png)
   
  제대로 선택되었는지 확인합니다. 잘 선택되었다면 **다음** 버튼을 클릭합니다.

  ![19-1 선택한 열 데이터 미리보기](/img/자동화%20프로그램/19-1%20선택한%20열%20데이터%20미리보기.png)

---

### 4단계: 격자(배치) 설정
- **행 수**: 세로로 배치할 명판 개수
- **열 수**: 가로로 배치할 명판 개수
- **간격**: 명판 사이 간격(mm 단위). 

  :::tip[격자 설정]
  설정 화면에서 행 수, 열 수, 간격에 대한 기본값을 지정할 수 있습니다.
  :::

  ![20 격자 설정](/img/자동화%20프로그램/20%20격자%20설정.png)
  
  0mm로 설정하면 솔벤 인쇄, UV 인쇄 전용 모드입니다.  
  자동으로 십자선이 도안 꼭지점에 추가됩니다.
  격자 설정이 끝났다면 **도안 생성 완료** 버튼을 누르세요.
  
  :::info
  결과 파일은 **도안 생성 결과물** 경로에 저장됩니다.  
  아무 설정을 하지 않았다면, 기본 저장 위치는 아래와 같습니다:

  ```
  내 문서 > Output 폴더  
  (예: C:\Users\사용자이름\Documents\Output)
  ```

  ※ 설정 화면에서 **도안 생성 결과물**의 저장 위치를 직접 변경할 수 있습니다.
  :::

  ![20-1 격자 간격 0](/img/자동화%20프로그램/20-1%20격자%20간격%200.png)

---

### 5단계: 명판 도안(DXF) 생성
- 모든 설정이 완료되면 **"명판 생성"** 버튼을 클릭합니다.
- 상태바에 진행 상황이 표시됩니다.
- 생성이 완료되면 `output/` 폴더에 DXF 파일이 저장됩니다.

#### 출력 파일 정보
| 항목 | 설명 |
|------|------|
| **파일명** | `년월일-거래처명-가로-세로-도안명.dxf` 형식으로 자동 생성<br />(예: `20250723-엠알씨이-75-25-MD`) |
| **파일 형식** | DXF (AutoCAD 호환) |


  ![23 도안 생성하고 결과물 보기](/img/자동화%20프로그램/23%20도안%20생성하고%20결과물%20보기.png)
